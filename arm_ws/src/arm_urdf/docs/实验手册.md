# 实验手册（软件已就绪，插线即可跑）

> 这份手册对应 `arm_urdf/tools/` 下的三个工具：`arm_check.py`、`sine_test.py`、`sine_plot.py`。

## 0. 前置检查（每次上电做一遍）

```bash
# Windows：确认 USB-CAN 已转发进 WSL
usbipd list                      # candleLight 应该是 Attached

# WSL：确认 can 接口和速率
ip -br link show | grep can      # 应该有 canX, state UP
```

如果 WSL 里没有 can：

```bash
# 先跑 Windows 上的自动重连脚本
.\can_autoconnect.ps1
# 或者手动 attach（busid 用 usbipd list 里看到的）
usbipd attach --wsl --busid 3-1
```

## 1. 体检（只读，不动电机）

```bash
cd ~/ros2_arm_ws/src/arm_urdf/tools
python3 arm_check.py
```

输出示例：

```
电机     状态        位置(rad)     电流(A)    母线(V)  模式
21       在线         0.1038       0.00       48.9     5
22       在线         0.0164       0.00       48.8     5
...
结论
  在线：5/5 台
  母线：48.6 ~ 48.9 V
  ✅ 可以开始实验
```

**看到 ⛔ 就不要跑实验**，先解决它列出来的问题。

## 2. 定点摆动（测跟随精度）

```bash
# 先预演（不动电机）
python3 sine_test.py --ids 21,22,23,24,25 --amp-deg 3 --freq 0.2 --cycles 10

# 确认后真跑（逐台）
python3 sine_test.py --ids 21,22,23,24,25 --amp-deg 3 --freq 0.2 --cycles 10 --yes-move

# 五台同时摆（更接近真实使用）
python3 sine_test.py --ids 21,22,23,24,25 --amp-deg 3 --freq 0.2 --cycles 10 --mode all --yes-move
```

## 3. 扫频（测带宽）

```bash
python3 sine_test.py --ids 21 --amp-deg 3 --sweep --freq-start 0.1 --freq-end 2.0 --freq-steps 6 --yes-move
```

耗时约 70 秒/台。想快就把 `--cycles-per-step` 调到 2。

## 4. 画图

```bash
python3 sine_plot.py sine_test.csv sine_test.png
```

或者跑实验时直接加 `--plot`。

## 5. 结果怎么读

| 指标 | 好 | 一般 | 有问题 |
|---|---|---|---|
| 幅值比 | 0.95~1.05 | 0.85~0.95 | < 0.8 |
| 相位滞后 | < 20° | 20~60° | > 90° |
| RMS 误差 | < 0.3° | 0.3~1° | > 2° |
| 峰值电流（±3°空载） | < 0.5 A | 0.5~1 A | > 1.5 A |
| 母线最低 | > 45 V | 42~45 V | < 40 V |

**几个典型症状：**

- **幅值比小、相位滞后大**：控制器太软，或限速太低 → 调 `--max-speed`、调增益
- **RMS 误差大但幅值比正常**：背隙/摩擦大 → 机械问题，加减速器也没用
- **某台明显比别的差**：那台的减速器或装配有问题
- **电流大、电压掉**：电源或摩擦是瓶颈

## 6. 常见故障

| 现象 | 原因 | 处理 |
|---|---|---|
| `没有 can 接口应答` | USB-CAN 没插 / 没 attach / 电机没上电 | 按第 0 步检查 |
| 某台离线 | 该总线断了，或电机地址不对 | `arm_check.py --ids 22` 单独查 |
| 中途停机并提示母线低 | 电源带不动 | 降速度/限流，或换电源 |
| 故障帧显示「欠压」 | 母线曾低于 12 V | **只能断电重启**，然后降载 |
| 桥 2 秒没收到指令自动停 | 看门狗（正常保护） | 检查界面是否还连着 |

## 7. 与上位机的配合

桥本身也可以给 Windows 上的界面用：

```bash
./arm_up.sh              # 真机，端口 5599
./arm_up.sh --dry-run    # 假数据，调界面用
./arm_down.sh            # 停机 + 关桥
```

注意：**跑实验时不要同时开界面**（两边都在写目标位置，会打架）。

## 8. 参数速查

| 参数 | 默认 | 说明 |
|---|---|---|
| `--amp-deg` | 5 | 单边摆幅（度），建议从 3 开始 |
| `--freq` | 0.25 | 摆动频率 Hz |
| `--cycles` | 10 | 摆多少周期 |
| `--mode` | per | per=逐台，all=同时 |
| `--limit-cur` | 2.0 | 限流 A |
| `--max-speed` | 2.0 | 限速 rad/s |
| `--vbus-min` | 40 | 低于此值立即停 |
| `--ramp` | 1.0 | 起始/结束渐变时间 s |
| `--watchdog` | 2.0 | 桥的断线自停时间 s |
